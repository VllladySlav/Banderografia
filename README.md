# БАНДЕРОГРАФІЯ

Електронний конкорданс творів-першодруків Степана Бандери.

## Що є в цій версії

- пошук однієї або кількох словоформ;
- реченнєвий контекст і контекст довільної глибини;
- об'єднання варіянтних словоформ;
- фільтр за статтями, у яких ужито знайдену словоформу;
- розподіл слововживань за статтями;
- частотний словник усього корпусу;
- частотний словник окремої статті;
- вкладка «Корпус» із паспортом корпусу;
- вкладка «Статті корпусу» з переглядом і завантаженням статей;
- вкладка «Варіянтні слова» з фільтром за типом варіянтности;
- експорт CSV і Excel;
- сторінка «Про сайт» із текстом опису й моделлю цитування;
- збережено напис «Слава Нації! / Смерть ворогам!» у футері.

## Вхідні файли

У папку `data/source` треба покласти:

```text
Перспективи Української Революції (першодруки).docx
Список статей Степана Бандери.docx
```

## Запуск

У терміналі PyCharm:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py --rebuild --mode sentence
.\venv\Scripts\python.exe -m streamlit cache clear
.\venv\Scripts\python.exe -m streamlit run app.py
```

## Для публікації онлайн

На GitHub / Streamlit Cloud потрібно завантажити код, папку `assets` і сформований файл:

```text
outputs/concordance_index.sqlite
```

Повні вихідні DOCX-файли з `data/source` можна не публікувати, якщо сайт має працювати лише з уже побудованим індексом.
